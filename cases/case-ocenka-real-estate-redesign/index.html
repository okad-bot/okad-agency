Ocenka RF — Real Estate Portal Redesign in 2 Weeks

Ocenka RF is a real estate evaluation service for mortgage applicants and professionals needing certified valuation reports. After a failed attempt by a previous agency, the client needed a fast, effective redesign of their portal and personal account system — delivered within weeks.

Project Background

Our mission was to build a modern UX/UI system that made it easy for users to:

  • Submit property data through a clear, guided flow
  • Receive detailed reports presented visually, not as raw documents
  • Track evaluation status with real-time dashboard updates
  • Navigate across devices without frustration

We delivered a fully functional design in 2 weeks, while also elevating the brand’s digital perception.

Core Challenges

  • Tight deadlines — The client had a strict go-live timeline. We worked in agile sprints with rapid feedback loops, simultaneously designing for desktop, tablet, and mobile.
  • Visually dry content — The core product was a 40-page property evaluation report. Presenting it in an appealing way was critical to avoid user fatigue.
  • Confusing UX for multiple audiences — Two main user groups (evaluation clients and mortgage report users) each needed clear paths with minimal overlap.

UX/UI Solutions

Tab-Based Interaction

The homepage uses tabs to let users quickly identify their path: “For Individuals” vs. “For Mortgage Clients.” This simple UX pattern drastically reduces cognitive load from the start.

Illustration-Focused UI

Instead of showcasing long, text-heavy documents, we built the interface around custom illustrations that visualize key steps and reassure users.

Minimalist UI with Smart Animations

We kept the interface clean — white space, intuitive spacing, soft transitions — and used microanimations to communicate states (loading, success, error) without overwhelming the user.

Responsive by Default

The portal was designed for all three screen types (desktop, tablet, mobile) from the beginning, ensuring consistent experiences everywhere.

Admin-Side Simplicity

We made sure the backend team could easily update report statuses, trigger notifications, and access user data from a clean internal layout.

Results

  • Delivery within 2 weeks, including all key flows and responsive versions
  • Reduced support inquiries through an intuitive dashboard
  • Better mobile conversion through clearer call-to-actions
  • Improved trust perception of the platform’s professionalism
  • B2B partner retention thanks to clear mortgage-client logic separation

Frequently Asked Questions

How long did the portal redesign take?

We delivered the full redesign — including all key flows and responsive versions for desktop, tablet, and mobile — in 2 weeks.

Can you design for both B2B and B2C users in one interface?

Yes. We used tab-based navigation to separate flows for individual property owners and mortgage clients, reducing cognitive load for both groups.

What impact did the redesign have on support tickets?

The intuitive dashboard reduced customer support inquiries, and clearer CTAs on mobile improved conversion rates.

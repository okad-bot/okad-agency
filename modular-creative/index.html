01 — Overview

Stop producing ads. Start producing components.

  • Modular creative = producing hooks, bodies, CTAs as separate components
  • 13 components can generate 72 unique ad variations
  • Cuts production cost 80%+ vs shooting individual ads

Traditional ad production creates finished, monolithic ads. If the hook doesn't work, the entire ad is wasted. If the body is strong but the CTA is weak, you can't fix it without re-shooting. Every ad is a single bet — and most bets lose.

Modular creative flips this model. Instead of shooting finished ads, you produce individual components: hooks (the first 3 seconds), body narratives (the middle), and CTAs (the closing). Then you combine them in the edit to create dozens of unique variations. If a hook fails, you swap it — without re-shooting the body or CTA.

This approach is the production backbone of performance creative. It's how brands producing 20–50+ new ads per month do it at a fraction of the cost of traditional production.

  • What: component-based ad production (hooks, bodies, CTAs)
  • Why: 72 ad variations from 13 components; 80%+ cost reduction
  • How: shoot components separately, combine in the edit
  • Key benefit: test and iterate at the component level, not the ad level
02 — Definition

What is modular creative?

  • A production system where ads are built from interchangeable parts
  • Each part (hook, body, CTA) is designed to work with any other
  • Component-level data tells you which piece drives performance

Modular creative is a production methodology where video ads are assembled from interchangeable components rather than produced as single, complete units. Each component — hook, body narrative, product demo, social proof clip, CTA — is designed to connect with any other component in the system.

A quick example

A supplement brand shoots a production session with three creators. Each creator records: 4 different hook openings, 2 body narratives (one about energy, one about sleep), 2 product demo clips, and 2 CTAs. That's 10 components per creator, 30 total. The editor combines these into 4 × 2 × 2 × 2 = 32 unique ad variations per creator, 96 total. The test spend to run all 96 variations: $4,800 at $50/day each for 1 day. Within a week, the team knows exactly which hooks, which body narratives, and which CTAs drive the lowest CPA.

What modular creative is not

  • Not random variation — each component is designed to connect with others. Random edits create Frankenstein ads.
  • Not dynamic creative optimization (DCO) — DCO is platform-side automated variation. Modular creative is production-side intentional variation.
  • Not just different thumbnails — true modular production changes the video content, not just the visual packaging.

04 — Components

The six component types

  • Hooks: the first 3 seconds — highest leverage, test first
  • Bodies: the core narrative (5–20 seconds)
  • CTAs, product demos, social proof clips, and supers/text overlays

Design for interchangeability

The key to modular creative is designing components that connect cleanly. Hooks should end with a natural transition point. Bodies should start without referencing specific hooks. CTAs should work regardless of which body precedes them. This requires scripting discipline — each component is self-contained but designed to flow into any adjacent piece.

05 — Workflow

Production workflow

  • Shoot all hooks in one session, all demos in another
  • Script for modularity — each piece must work independently
  • Edit combinations systematically using the naming convention

The five production stages

  1. Script modular concepts. Write scripts where each section (hook, body, CTA) is a standalone module. Include transition notes so editors know where components connect. Mark which components are interchangeable.
  2. Batch-shoot hooks. All hooks for one concept in a single session. Same creator, same setup, different openings. Shoot 6–10 hook variants — hooks are the highest-leverage component. For hook rate optimization, shoot multiple hook types: questions, stats, before/after, controversy.
  3. Batch-shoot bodies and demos. Separate sessions for body narratives, product demonstrations, testimonials, and CTAs. Each body should start with a clean transition that works after any hook.
  4. Assemble combinations. Edit hook + body + CTA combinations using a systematic approach. Use the naming convention (Section 08) to track every variation. An editor can produce 20–40 combinations per day with properly organized components.
  5. QC and export. Review each combination for flow and timing. Export in platform-specific formats: 9:16 for Reels/TikTok/Shorts, 1:1 for feed, 16:9 for YouTube in-stream. Apply text overlays appropriate to each platform.

06 — Testing

Testing approach: hooks first, then bodies, then CTAs

  • Test hooks first — they have the highest leverage on performance
  • Keep everything else constant when testing one component type
  • Component-level testing produces 3x the learnings of ad-level testing

Modular creative enables a fundamentally different testing approach. Instead of testing "which ad wins," you test "which component wins." This produces far more actionable data because you can isolate exactly which element drives performance.

The testing sequence

  1. Test hooks. Keep the same body and CTA. Run 6 hook variants. Measure hook rate and early CPA. Identify the top 2–3 hooks.
  2. Test bodies. Attach the winning hooks to 4 different body narratives. Keep the CTA constant. Measure CPA and conversion rate. Identify the top 1–2 bodies.
  3. Test CTAs. Attach winning hook + winning body to 3 different CTAs. Measure CPA. CTAs have the smallest marginal impact, so test them last.
  4. Scale the winning combination. The best hook + best body + best CTA is your champion ad. Produce variations of this combination: new creators, different angles on the same hook, minor edits.

This follows the same creative testing hierarchy: test the highest-leverage variable first, find the winner, then move to the next level. Each stage builds on the previous winner, compounding learnings.

08 — Naming & Analytics

Naming conventions, storage, and component analytics

  • Naming: [concept]_[hook-variant]_[body-variant]_[cta-variant]
  • Consistent naming enables component-level analytics
  • Tag components to identify which piece drives performance

The naming convention

A consistent naming convention is non-negotiable for modular creative at scale. Without it, you can't tell which components are in which ad, and you lose the ability to analyze at the component level.

Format: [concept]_[hook]_[body]_[cta]

Example: skincare-routine_hook-question_body-beforeafter_cta-tryfree

Example: productivity-app_hook-stat_body-demo_cta-linkinbio

Example: energy-supplement_hook-controversy_body-testimonial_cta-20off

Component-level analytics

With consistent naming, you can aggregate performance data by component. Instead of asking "which ad won?" you can ask more powerful questions:

  • Which hook performs best across all body combinations? — aggregating CPA for all ads with "hook-question" shows hook-level performance
  • Which body converts best regardless of hook? — aggregating CPA for all ads with "body-demo" reveals body-level performance
  • What is the single best combination? — the winning hook + winning body + winning CTA, identified through component-level data

Storage and organization

Organize your asset library by component type, not by ad. Folders: Hooks, Bodies, Demos, Social Proof, CTAs, Supers. Within each folder, use the naming convention. Tag components with metadata: concept, creator, date, platform, hook type. This makes it fast to find and reuse winning components in future combinations.

09 — Scaling

Scaling winners: more variations of what works

  • Found a winning hook? Create 5 more variations in that style
  • Winning components get more variations; losing components get replaced
  • Modular scaling extends creative life and delays ad fatigue

Once you've identified winning components, the scaling strategy is straightforward: produce more variations of what works and attach them to other winning components. This extends the creative's lifespan and multiplies the output of your testing program.

Scaling playbook

  1. Winning hook → more hook variations. If "stat hooks" win, produce 5 more stat hooks with different numbers, different framings, different creators. Test each with the winning body.
  2. Winning body → attach to new hooks. If a product demo body outperforms, attach it to every hook type you haven't tested yet. This may unlock combinations you hadn't considered.
  3. New creators on winning scripts. Have different creators perform the same winning hook + body combination. Creator variation extends the creative's life with each new audience.
  4. Minor edits on fatiguing winners. When a winning ad starts to fatigue, produce small variations: new text overlays, different music, slightly re-cut timing. These minor edits can extend lifespan by 1–2 weeks before a full refresh is needed.

10 — Glossary

Key terms

Modular creative
A production methodology where video ads are built from interchangeable components (hooks, bodies, CTAs) rather than produced as single, complete units.
Component
An individual, self-contained piece of a modular ad: a hook, a body narrative, a product demo, a social proof clip, a CTA, or a text overlay.
Hook
The first 3 seconds of a video ad. The highest-leverage component — tested first in the modular framework.
Body narrative
The core content of the ad (5-20 seconds): problem/solution, product demonstration, testimonial, or educational content.
CTA (call to action)
The closing component (2-5 seconds): 'Try it free,' 'Link in bio,' 'Get 20% off.' Lowest leverage — tested last.
Super / text overlay
Bold text placed on the video to reinforce key messages. Can be swapped independently of other components.
Component-level analytics
Aggregating ad performance data by individual component to identify which hook, body, or CTA drives results — not just which ad won.
Naming convention
Systematic file naming ([concept]_[hook]_[body]_[cta]) that enables component-level tracking and analytics.
Batch shooting
Recording all components of one type in a single session — e.g., all hooks at once, all demos at once — for production efficiency.
Creative fatigue
The decline in ad performance from audience overexposure. Modular creative extends lifespan by enabling rapid variation production.
Dynamic Creative Optimization (DCO)
Platform-side automated variation of ad elements. Different from modular creative, which is production-side intentional variation.
11 — FAQ

Frequently asked questions

What is modular creative?+
Modular creative is a production methodology where ads are built from interchangeable components — hooks, bodies, CTAs — rather than produced as complete, standalone ads. 6 hooks x 4 bodies x 3 CTAs = 72 unique ad variations from just 13 components.
How much does modular production save vs traditional?+
80%+ cost reduction. 72 traditional ads at $500 each would cost $36,000+. 13 modular components that generate 72 variations typically cost $5,000-$8,000 to produce.
What should I test first in a modular system?+
Hooks, always. They have the highest leverage on ad performance. Keep the body and CTA constant, test 6 hook variants. Once you find winning hooks, test bodies against them. CTAs last — they have the smallest marginal impact.
How do I name modular creative files?+
Use the format: [concept]_[hook-variant]_[body-variant]_[cta-variant]. Example: skincare-routine_hook-question_body-beforeafter_cta-tryfree. Consistent naming is non-negotiable — without it, you can't do component-level analytics.
What if the components don't flow together?+
Design for interchangeability from the start. Hooks should end at natural transition points. Bodies should start without referencing specific hooks. CTAs should work after any body. This requires scripting discipline — each component is self-contained but designed to connect cleanly.
Is modular creative the same as dynamic creative optimization?+
No. DCO is platform-side automated variation — the algorithm mixes and matches elements. Modular creative is production-side intentional variation — you design, produce, and test specific combinations. They can work together, but they're different concepts.
How does modular creative help with ad fatigue?+
When a winning ad starts to fatigue, you can quickly produce variations: swap the hook, change the music, add new text overlays. This extends the creative's lifespan without starting from scratch. Modular production makes the response to fatigue faster and cheaper.
What tools do I need for modular creative?+
Standard video editing software (CapCut, Premiere, DaVinci Resolve), a file naming convention, a component library (organized by type: hooks, bodies, demos, CTAs), and a spreadsheet or tool to track which components are in which ads.
How many components should I start with?+
Start with one concept: 6 hooks, 2 bodies, 2 CTAs = 24 variations. This is enough to test hook types and body narratives. Once you have winners, expand to more concepts and more components.
